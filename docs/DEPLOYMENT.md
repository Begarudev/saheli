# Deployment

## Local dev

```bash
nvm use         # Node 20
npm install
npx expo start
```

Press `a` for an Android emulator, or scan the QR with Expo Go on an Android device.

## Android APK

```bash
npx expo prebuild -p android
cd android && ./gradlew assembleRelease
```

Release keystore lives at `android/app/saheli-release.keystore` (untracked).
Set `SAHELI_RELEASE_KEYSTORE_PASSWORD` and `SAHELI_RELEASE_KEY_PASSWORD` in
your shell before building.

## Environment

```bash
cp .env.example .env
# EXPO_PUBLIC_SARVAM_API_KEY=...
```

Without a key the Sarvam adapter (`src/services/sarvam.ts`) returns mocked
responses for `stt`, `tts`, `chat`, and `ocr` so the app remains usable end
to end.

## Embeddings

`src/data/{rights,schemes}.embeddings.json` are regenerated by:

```bash
node scripts/build-embeddings.mjs
```

The Sarvam embeddings endpoint is used when a key is present; otherwise a
deterministic hash fallback runs so RAG still produces stable rankings.
